# Contributors

Each file in this folder is an **opt-in** public profile shown on [grcskills.io/contributors](https://grcskills.io). Add yours in the same pull request as your first contribution.

1. Copy `harrywestuk.md` to `<your-github-handle>.md` (lowercase).
2. Fill in the frontmatter. Only these fields are accepted: `name`, `github` (must match the file name), `kind` (`person` or `organisation`), `role` (80 characters max), `website` and `linkedin` (https URLs). There is deliberately no field for email, location or employer.
3. Write a short bio below the frontmatter: 20–300 words, plain Markdown, no HTML.
4. To be credited as a skill author, add your handle to `metadata.author` in that skill's `SKILL.md` (comma-separated, e.g. `author: grcmana, your-handle`).

Your avatar is taken from your public GitHub profile. To remove your profile, open a PR deleting the file, or ask a maintainer and we will do it for you.
